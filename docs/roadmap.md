# 路线图

> 本路线图覆盖两个组件的近期修补、中期贯通与中长期能力扩展。
> 状态说明：🔲 未开始 · 🔨 进行中 · ✅ 已完成

## 分层目标

```
L4  决策层    机组组合 / 储能调度 / 风险成本          🔲
L3  场景层    概率预测 · 时空相关场景生成              🔲   ← 中长期重点
L2  治理层    Active/Candidate · 门禁 · 审计          ✅（energy-tsf）
L1  模型层    谱系 · 滚动评测 · 集成                  ✅（energy-expert）
L0  数据层    y/H/F 协议 · 时序切分 · 时点对齐         ✅（energy-expert）
```

当前两个组件覆盖 L0–L2。往上（L3 场景层、L4 决策层）是本项目下一阶段的主要增量。

## 中期（两层贯通）

| 项 | 状态 | 说明 |
|---|---|---|
| 建模结果自动成为运行系统 Candidate | 🔲 | 引擎的 leaderboard + 集成权重 → 适配层 → `Candidate` → 发布门禁 |
| 统一模型能力契约 | 🔲 | 引擎 `model_catalog()` 能力声明 ↔ 运行时 `ProviderCapabilities`，避免给不支持的模型喂未来协变量 |
| 训练经验跨场站复用 | 🔲 | 从《训练经验报告》提取可复用经验，辅助新场站冷启动选型，最终仍由滚动验证检验 |
| NWP 发布时间 / 版本自动核验 | 🔲 | 当前引擎不核验预报发布时间，存在信息泄漏风险 |
| 基础模型可用性 | 🔲 | 引擎侧仅 zero-shot；运行时侧要求本地权重与钉死版本，需提供权重准备脚本 |
| 多场站规模化 | 🔲 | 引擎已有 Ray/Dask/Spark 后端，需与运行时的场站资产库对接 |

## 中长期（场景层与决策层）

| 项 | 状态 | 说明 |
|---|---|---|
| 概率 / 分位数预测 | 🔲 | 当前两个组件都只做点预测。电网调度需要 P10/P50/P90，改造越晚成本越高 |
| 时空相关场景生成 | 🔲 | 多场站联合场景，而非独立边际分布 |
| NWP 误差建模 | 🔲 | 新能源不确定性很大一部分来自气象预报误差，不应把 NWP 当作给定真值 |
| 电网拓扑与运行约束接入 | 🔲 | 潮流、断面、爬坡等约束 |
| 决策闭环评估 | 🔲 | 从 MAE/RMSE 转向调度成本、弃风弃光、风险指标 |

## 明确的非目标

以下内容**不在**本项目范围内，避免范围蔓延：

- 不做通用 AutoML 框架（不追求在任意表格 / 视觉任务上通用）。
- 不做气象预报本身（NWP 作为外部输入）。
- 不做 SCADA / 数据采集与硬件接入。
- 不复制基础模型权重到资产库，不在运行时下载权重。
