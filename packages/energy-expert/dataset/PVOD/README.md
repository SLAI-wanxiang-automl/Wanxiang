# PVOD station00 示例数据

当前仓库附带 station00.csv（约 2.8 MB），不代表完整 PVOD 多场站数据集。

- 28,896 行，15 分钟间隔，2018-08-15 16:00 至 2019-06-13 15:45。
- date_time：时间；power：目标功率；lmd_*：历史气象观测；nwp_*：数值天气预报。
- 保留原始字段和值，未推断功率单位、时区或场站容量。使用前应核对原始数据说明。
- examples/pvod_split_pipeline.py 的 load_station() 去重并截取最后缺口之后的连续区间：15,802 行，2018-12-31 01:30 至 2019-06-13 15:45，不插值。
- nwp_* 需要满足预测起点已可获得的条件；本文件不提供可自动核验的预报发布时间/版本记录。

运行方法见仓库根目录 README 的 PVOD 教程。此文件来自项目现有数据目录，由项目所有者指定随私有仓库上传。目录内尚无原始来源链接、论文引用或数据许可证文件，代码 MIT 许可证不自动适用于该数据。后续公开分发时应补齐原始来源与授权信息。
