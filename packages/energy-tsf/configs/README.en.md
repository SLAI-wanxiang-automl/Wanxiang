# Configuration files

- `workflows/modeling.toml`: modeling workflow defaults.
- `workflows/forecast.toml`, `backtest.toml`, and `update.toml`: task-specific defaults.
- `providers/*.toml`: provider definitions and local foundation-model checkpoint paths.
- `stations/*.toml`: registered station metadata examples.
- `tracks/*.toml`: explicit permissions for training, forecasting, backtesting, and updating.

Use `README.md` in this directory for the Chinese version. Copy example files before editing them for a real station or environment.
